日常點用

喺網站

  • 新增：右上「新增活動」→ 填標題、類型、場地、時間 → 儲存
  • 修改：撳活動 →「✏️ 編輯」；刪除：撳活動 →「🗑️ 刪除」
  • 多堂課程：新增時填第一堂日期時間、共幾堂、每 1／2／3／4 星期一次 → 自動推算每堂，可逐堂再改
  • 改課程：揀「只改這一堂」或「整個課程」（可加堂、刪堂，自動重新編號）
  • 備註：所有活動都可以寫，登入後先睇到
  • 手機：用「列表」檢視

喺 Google 日曆

  • 顏色＝類型（見下表）
  • 地點或標題寫場地：1S、1B、2/F，多過一個寫 1S + 1B
  • 課程：用「重複」建立
活動｜火鶴紅 課程／班｜香蕉黃 參觀／Booking｜薰衣草紫 通知｜石墨灰 其他｜鼠尾草綠 未分類
  • 場地：1S＝1/F 細房、1B＝1/F 大房、2/F＝2 樓。
  • 每日望一望右上：綠色「已同步」＝正常；「⚠️ 需處理」＝有活動未分類，撳入去補返。

點運作

網站 ──新增／修改／刪除──▶ 日曆資料橋 ──▶ Google 日曆（即時） Google 日曆 ──▶ 日曆資料橋 ──▶ 網站（每 30 秒；切返網站即更新）
  • 活動只存喺 Google 日曆，所以手機、電腦永遠一致。
  • Firebase 只負責登入同更表。
  • 網站唔使連接 Google，唔會過期。

以後點改（用 Manus）

改網站（畫面、功能、文字）

  1. 叫 Manus 改 GitHub whiteclub-calendar
  2. Manus push 到 main
  3. Vercel 約 1 分鐘自動上線
  4. 開網站按 ⌘⇧R 檢查

改規則（類型、顏色、場地、關鍵字）

  1. 叫 Manus 改 apps-script/Code.gs 最頂嘅 CONFIG
  2. 人手將新 Code.gs 貼入 script.google.com，⌘S
  3. 部署 → 管理部署作業 → ✏️ 編輯 → 新版本 → 部署
  4. 網站自動跟新規則，唔使改網站
MANUS 指令範例

「打開 GitHub repo whiteclub-calendar，先讀 CLAUDE.md。我想新增類型『私人租場』，Google 用葡萄紫（colorId 3）。改完執行 node scripts/test-feed.cjs，測試通過先 push 到 main。」

「打開 GitHub repo whiteclub-calendar，先讀 CLAUDE.md。手機列表想顯示到 4 星期內嘅活動。改完 push 到 main。」

⚠️ Apps Script 一定用「管理部署作業 → 編輯 → 新版本」。如果撳咗「新增部署作業」，網址會變，要叫 Manus 將 index.html 入面嘅 CALENDAR_FEED_URL 改成新網址。
  • 改壞咗：Vercel → Deployments → 揀上一個正常版本 → Promote to Production。
  • Manus 唔可以：自己改 Apps Script，要人手貼。
  • Manus 一定要守：網站唔可以直接寫 Google 或 Firebase 活動，只可以經資料橋（詳見 CLAUDE.md）。

出問題

情況處理
同步狀態紅色撳一下重試；再唔得就打開資料橋網址，睇吓係咪 "ok":true
儲存失敗「請先登入」重新整理網頁，用 community@whiteclub.co 再登入
新網址登入唔到Firebase → Authentication → Settings → Authorized domains 加新網址
活動冇出現確認係 community@whiteclub.co 主日曆，日期喺 62 日前至 300 日後之內
